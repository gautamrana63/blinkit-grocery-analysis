# blinkit-grocery-analysis
 BlinkIT Grocery Sales Analysis - Power BI Dashboard

This project presents an interactive Power BI dashboard analyzing sales performance for BlinkIT, a last-minute grocery delivery platform. The dashboard provides a clear picture of item performance, outlet metrics, and sales distribution across different tiers and product types.

# Overview

The goal of this analysis is to:

- Track and compare total sales across item types and outlets  
- Analyze fat content and outlet size/location distribution  
- Measure key performance metrics like average sales, item count, and average rating  
- Provide visibility into sales patterns over time

# Dashboard Features

- KPI Cards: Total Sales, Average Sales, Number of Items, and Average Rating  
- Item Type Breakdown: Bar charts showing top-performing grocery segments  
- Sales by Fat Content: Donut chart comparison (Low Fat vs Regular)  
- Time Series Visualization: Sales trends by year (2012–2022)  
- Outlet Analysis: Sales breakdown by Outlet Size, Location Tier, and Type  
- Filters: Slicers for Item Type, Outlet Size, and Outlet Location  
- Interactive Views: Toggle between Total Sales, Avg Sales, No. of Items, and Ratings  

# Files Included

- `blinkit.pbix`: Power BI report file  
- `BlinkIT Grocery Data.xlsx`: Data source used for building the report

# Tools Used

- Power BI Desktop  
- DAX for calculated metrics  
- Power Query for data transformation  
- Excel for structured data input
